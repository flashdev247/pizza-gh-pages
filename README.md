# Damina Pizza — Website Nhà Hàng Pizza

## Giới Thiệu

**Damina Pizza** là website giới thiệu nhà hàng pizza tại Hà Nội. Trang web nhiều trang với menu có tính năng tìm kiếm trực tiếp, form đặt bàn và bản đồ Google Maps. Đây là website showcase — không có hệ thống đặt hàng online thực sự.

---

## Nội Dung Website

| Trang | Nội dung |
|-------|----------|
| Trang chủ | Slider ảnh nhà hàng, món nổi bật, form đặt bàn (ngày + giờ), thống kê (số món, khách hàng...), giới thiệu nhà hàng |
| Menu | Thực đơn tìm kiếm trực tiếp (gõ để lọc), phân tab: Pizza / Đồ uống / Burger / Mì Ý |
| Dịch vụ | Giới thiệu các dịch vụ nhà hàng |
| Về chúng tôi | Câu chuyện nhà hàng |
| Blog | Bài viết ẩm thực |
| Liên hệ | Bản đồ Google Maps, thông tin liên hệ |

---

## Thực Đơn

| Danh mục | Ví dụ |
|----------|-------|
| Pizza | Pizza Ý, Hawaii, Hy Lạp, thịt xông khói... |
| Đồ uống | Nước chanh, dừa, nước ngọt |
| Burger | Bò phô mai, gà giòn, đặc biệt |
| Mì Ý | Sốt bò bằm, sốt kem, hải sản |

---

## Tính Năng Kỹ Thuật

- Tìm kiếm menu trực tiếp (filter real-time bằng JavaScript)
- Owl Carousel image slider
- Form đặt bàn với Bootstrap Datepicker + Timepicker
- Google Maps embed
- Hiệu ứng AOS scroll animations
- Responsive (Bootstrap 4)
