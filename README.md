# 🍕 Pizza — Website Đặt Hàng Pizza Trực Tuyến

## Giới Thiệu

Pizza là website trưng bày và đặt hàng pizza trực tuyến với giao diện đẹp mắt, sinh động. Dự án được triển khai trên GitHub Pages như một trang web tĩnh, phù hợp làm portfolio, landing page cho cửa hàng pizza hoặc demo giao diện thương mại điện tử thực phẩm.

## Tính Năng Chính

### 👤 Dành Cho Khách Hàng

- 🏠 **Trang chủ hấp dẫn**: Giao diện bắt mắt với hình ảnh pizza chất lượng cao
- 📋 **Thực đơn đa dạng**: Danh sách các loại pizza với mô tả nguyên liệu và giá cả
- 🛒 **Đặt hàng**: Chọn size, số lượng và tùy chỉnh topping theo sở thích
- 📍 **Thông tin cửa hàng**: Địa chỉ, giờ mở cửa và bản đồ vị trí
- 📞 **Liên hệ đặt hàng**: Thông tin liên lạc để gọi điện hoặc nhắn tin đặt hàng
- 🎉 **Khuyến mãi**: Hiển thị các chương trình ưu đãi và combo đặc biệt

## Công Nghệ Sử Dụng

| Thành phần | Công nghệ |
|---|---|
| Frontend | HTML5, CSS3, JavaScript |
| Hosting | GitHub Pages |
| Loại | Website tĩnh (Static) |

## Hướng Dẫn Cài Đặt

### Xem Trực Tiếp
Truy cập website qua GitHub Pages:
```
https://flash-dev-team.github.io/pizza-gh-pages/
```

### Chạy Local

1. **Clone dự án**
   ```bash
   git clone https://github.com/Flash-Dev-Team/pizza-gh-pages.git
   cd pizza-gh-pages
   ```

2. **Mở file `index.html`** trong trình duyệt hoặc dùng Live Server (VS Code extension)

### Tùy Chỉnh Nội Dung
- Cập nhật thực đơn và giá cả trong file HTML
- Thay thế hình ảnh trong thư mục ảnh
- Điều chỉnh thông tin cửa hàng (địa chỉ, số điện thoại, giờ làm việc)
